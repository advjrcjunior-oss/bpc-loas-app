## 2024-05-26 - Detect Duplicates File Read & Hash Optimization
**Learning:** In applications dealing with a large batch of PDFs and images, avoiding unnecessary processing operations by using pre-filters can save large amounts of I/O cycles and processing time. Reading large files entirely into memory at once causes immense memory spikes. The `detect_duplicates` function originally processed and read every single file byte into memory.
**Action:** Implemented a pre-filter using `os.path.getsize(path)` to ensure files are only hashed if another file in the folder shares the exact same size, saving an O(N) hash compute step. Furthermore, when files do need hashing, read them in 64KB chunks (`iter(lambda: fh.read(65536), b"")`) to preserve memory, reducing the overall footprint by avoiding reading entire multi-megabyte PDFs into memory simultaneously.
