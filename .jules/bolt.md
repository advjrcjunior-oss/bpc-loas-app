## 2024-06-17 - Connection Pooling & LRU Cache in External APIs
**Learning:** In the batch processing pipeline, external API calls (ViaCEP, CPF/CNPJ) can become severe N+1 bottlenecks. However, `@functools.lru_cache` cannot be used blindly. For CPF/CNPJ responses (`cpfcnpj_service.py`), downstream functions (like `validar_dados_cliente`) mutate the returned dictionaries, leading to cache corruption if `lru_cache` is used. On the other hand, ViaCEP responses (`legalmail_service.py`) are strictly read-only within their functions and safe to cache. In both cases, `requests.Session()` must be used to reaproveitar TCP connections and improve baseline HTTP performance safely.
**Action:** Always utilize `requests.Session()` for external API endpoints that are called repeatedly during batch processes. Only apply `@functools.lru_cache` if you can guarantee the returned dictionaries/objects are not mutated by any downstream consumer (e.g., ViaCEP is safe; CPF/CNPJ is not).
